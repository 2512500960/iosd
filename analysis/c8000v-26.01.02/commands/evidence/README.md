# 条件、参数、状态和缺口参考

[命令总索引](../README.md)

命令页链接到“序列”，按路径顺序列出明细 ID。明细保留已取得字段；映像地址显示为十六进制 RVA，历史运行时地址标为 captured VA。

`kind` 表示动作种类；`function_rva` 是回调；`expected` 是路径所需结果；`evaluated=false` 表示符号约束；`evaluated=true` 按该动作的静态模型解释。`field_offset` 是结构偏移，`min/max` 是参数范围。

状态效果是路径中的赋值或回调模型，设备上的实际效果另按执行证据判断。缺口字段包括未知动作、描述符、回调和条件安装。候选注册保留 key、类型、创建点和安装状态。

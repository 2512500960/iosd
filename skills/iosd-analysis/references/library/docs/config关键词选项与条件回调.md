> 样本分析资料：保留适用版本、条件和未知项。原始捕获保留在本地；标注的历史材料路径用于定位来源。


本轮结果从 关键词选项与间接条件报告（历史材料路径：`../reports/runtime-comparison-20261029/options/index.html`） 阅读。输入 MD5、运行时基址与此前一致，采集期间保持暂停，没有执行任何目标回调或设备命令。

## 选项表怎样变成命令

一个 parser 节点可以承载多个关键词。例如当前已恢复 `platform broadband` 的 `1K` 到 `8K`，以及 `cef table consistency-check` 的 `IPv4`、`IPv6`、`Binding-Label`。每个词有自己的数值、最短匹配和状态写入，不能把选项表简单压成一个字符串，也不能只保留第一个词。

本样本直接数组的每项为 24 字节：关键词指针 `+0`，帮助指针 `+8`，BE32 数值 `+16`，BE32 最短匹配 `+20`。关键词指针为 NULL 才表示表尾；数值 0 是有效选项。读取帮助文字失败也不会删除已经取得的关键词。

带 `list` 的适配器会调用生成器。生成器可能反复改写同一临时条目，再把地址返回。因此，某一时刻临时缓冲区里的一个词不等于整个词表。本轮只对已审查的有限生成规则建立模型，例如固定索引边界、按启用槽枚举的三个选项；其他生成器保留函数地址、调用条件和未知入口。动态适配器传入清零的临时记录时，首次索引的含义也与 NULL 起点不同，已经单独处理。

通用实现位于 `iosd_helper/option_tables.py`，样本相关地址与有限规则位于本轮 `analysis-profile.json`，附带消费函数证据与哈希。命令名称不作为注册判断规则。当前已枚举到的词表与整份二进制的潜在词表范围仍有区别。

## 条件怎样保留

| 条件 | 当前能说明什么 | 尚未完成的部分 |
|---|---|---|
| 选项启用槽 | CEF 三个候选的槽，本次 BE32 都为 1 | 其他权限和上下文检查仍存在 |
| service internal | NBAR 一些自动学习路径的直接关键词门控，本次值 0，因此该项检查拒绝 | 不据此推断所有 NBAR 命令都被拒绝 |
| ORSET / ORTEST | 按位写入解析对象；ORTEST 可要求相应位未设置 | 未跟踪字段和更复杂数据流仍为条件 |
| 生成器包装条件 | 部分包装器要求 CSB `+0x28C2` 的 bit 0 为 0 才调用生成器 | 当前待分析命令的 CSB 尚未构造或取得，不能拿任意暂停内存代替 |
| 无参条件回调 | 部分纯比较 getter 读取同一个全局值，与 0 或 1 比较；本次该值为 0 | 复杂注册查询、主查询结果和回调副作用仍有未知 |
| 歧义和剩余输入 | 影响语法后续分支的选择 | 取决于当前命令解析过程中的计数、字符串和位置，未执行检查 |

CSB 是当前这一条命令的解析上下文。它的条件与普通全局启用变量不是同一个概念。本次对纯全局 getter 的结果来自“保存的字节＋已审查的返回表达式”，并未真正调用 getter。快照不满足的分支也保留，用于分析后续状态。

另一个例子包含注册查询与间接回调：先查询参数 `(27, 1)`；主查询失败后才使用回调槽，槽为空又有回退值。读到槽地址或发现它为空，并不足以证明整个检查的结果，因为主查询结果仍未知。报告保留实际回调槽、已观察到的目标和这层前置条件。

## 两个容易看错的动作

`multiple_funcs_action` 的载荷 `+16`、`+24` 是语法目标。消费函数先调度 alternate，再根据两个上下文检查结果的逻辑或选择目标。它不是从这两个位置取出函数来调用。此前未解释的这两条分支现已纳入图。

`test_func_action` 则确实包含一个无参回调：载荷 `+0` 是回调，`+8` 为假分支，`+16` 为真分支。回调没有被执行；两条边和条件同时保留。未审查的回调副作用也保留为 gap，不会因为找到函数地址就宣称已理解其行为。

## 怎样阅读输出

报告分别列出全部已取得选项、生成器及未解析入口、间接条件分支、普通路径示例和逐项选项变体。`conditional-transitions.jsonl` 保留每个选项的 token、值、效果和条件，优先路径示例不会把其他选项从这里删掉。

逐项变体采用“重放现有前缀—选中某个选项—应用它的状态写入—重新求解有界后缀”。这比只替换显示文字更可靠；某个选项改变 sense 或其他跟踪状态时，后面的路径也应变化。当前变体仍是有界示例，不是所有排列和重复组合。完整前缀、后缀、条件和剩余 gap 另存 JSONL。

本轮解释了大量语法动作，同时也发现了新的目标和条件，所以总不确定记录数不要求单调下降。报告区分“不透明语法动作”“词表生成器未解析”“条件未求值”“回调副作用未知”，不会把它们合并成一个命令数量。

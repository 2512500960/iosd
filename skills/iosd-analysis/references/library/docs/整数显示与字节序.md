# 整数显示与字节序

> 历史分析资料：保留样本、条件和未知项。原始捕获及 GUI 实验不随 skill 分发；历史材料路径用于定位已有证据，不表示文件已包含。


iosd Helper 0.6.2 在 IDA 9.1 提供两种显示入口：数据/汇编视图使用原生自定义数据格式，Hex-Rays 视图为选中的整数常量添加解码注解。功能不交换数据库或目标内存中的字节，也不改写 ctree 常量及表达式。

## 使用方法

1. 更新插件文件和 `iosd_helper` 包。开发方式使用 IDA 的 **File → Script file / Alt+F7** 重新运行项目的 `dev_load.py`；开发加载方式与安装插件方式保持一种。
2. 数据/汇编视图中，将光标放在 WORD、DWORD、QWORD 数据项，或者指令的立即数操作数上。Hex-Rays 中，将光标放在整数常量上。
3. 右键选择 **iosd Helper → Integer display / BE interpretation...**。
4. 在预览中选择 BE16、BE32、BE64 的十六进制、无符号十进制或有符号十进制格式。仅在确认是相应 iosd 指针编码时选择 **tagged pointer (clear bit 63)**。

数据项按已经定义的元素宽度提供选项，不会自动创建或拆分数据。数组沿用原数据项的格式，预览使用其首元素。指令和伪代码常量允许明确选择能够容纳该值的宽度；例如 64 位操作数中的一个常量也可能需要按 32 位解释。

格式也会注册到 IDA 标准数据格式设施，菜单中的名称以 `iosd: BE...` 开头。插件主菜单中的 Integer display 项提供操作提示；实际选择数值应在相应视图右键完成。

## 可以看到什么

| 对象 | 原始表示 | 选择后的显示 |
|---|---|---|
| 数据字节 `00 00 00 12` | x86 小端数据行 `dd 12000000h` | `dd BE32(18)` |
| 立即数 `0x1000000`，按 32 位交换字节 | 指令中的 `1000000h` | 指令中显示 `BE32(1)` |
| 同一伪代码常量 | `v48 = 0x1000000;` | `v48 = 0x1000000; // iosd-view: raw 0x1000000 -> BE32(1)` |
| 大端字节 `80 00 00 00 00 00 00 01` | 普通 BE64 保留最高位 | 专用指针格式显示 `IOSD_BE64_PTR(0x0000000000000001)` |

BE 表示按大端解释字节序，并非翻转每个字节中的 bit。无符号整数格式保留全部位；只有专门的 tagged 指针格式在按大端解码后清除 bit 63。它不自动套用到 GOT、所有 so、所有地址或其他 iosd 版本上，也不会自动创建引用。

原生格式的 `BE32(1)` 是显示文字，不是写进二进制的函数调用。对指令常量的字节重建使用数据库处理器字节序和用户选择的宽度；不会因为整数恰好看起来像地址就自动转成指针。

## 两个视图的处理边界

原生格式使用 IDA 的 `data_format_t`、`attach_custom_data_format` 和 `op_custfmt`。按用户选择修改的是操作数表示属性；它会替换该操作数原来的显示方式，例如原先的数值或 offset/枚举表示。选择预览最后一行可恢复标准十六进制；若要还原更早的特殊表示，使用 IDA 撤销或重新设置原表示。

Hex-Rays 使用 ctree 数字项的打印锚点定位，为其所在行追加注解。它不会按字符串全局替换相同数字，不会改动同值字符串、其他常量或用户注释。常量原值保留在表达式中，便于区分程序实际参与运算的值与手工选择的解码解释。

伪代码注解仅在当前会话中生效，选择最后一行可移除。F5 或其他操作重新生成伪代码时会清除这些临时注解，需要重新选择；不会把旧 ctree 索引迁移到新的同值常量上。关闭或重载插件也会清理它拥有的注解。

当前入口处理整数常量；它不执行 `_byteswap_*` 表达式、不求值变量、不读取表达式指向的运行时对象。没有 Hex-Rays 时，数据/汇编格式仍可使用。

## 验证范围

本机 IDA 9.1 已验证数据行、立即数和带真实 ctree 锚点的伪代码注解。测试临时设置再恢复操作数表示，核对原字节、原指令/数据行、操作数 flags 和 ctree 常量均未改变，并验证移除注解、重新生成文本及注册清理。

现场结果保存在 IDA 9.1 显示验证记录（历史材料路径：`../reports/integer-display-ida91-smoke.json`）。这证明当前版本的注册和渲染路径可用，不代表自动确定任意字段的字节序或指针语义。

## 导出的是什么

真实 parser 是共享、带条件且可能有循环的图。`tree/nodes.jsonl` 和 `tree/edges.jsonl` 保留已采集图；`tree/paths.jsonl`、文本和 HTML 树是每个 EOL/跟踪上下文的一条有界示例。示例数不是全部语法数，也不是可执行命令数。当前连接图不加入静态候选注册边；静态候选另行保留和对照。

动态槽链取得 1,783 条记录，待绑定链取得 245 条记录，两者均到达 NULL。静态注册对照保留原来的 4,564 条记录。`observed_binding_evidence` 表示同 key/root 在相应 type-1 alternate 链或 type-2 改写指针上有直接证据；`connected_modes` 只表示片段根出现在保留条件的模式投影中。二者不是同一证据。

待绑定项、未观察到绑定的片段、无已知模式的定义、未知动作、未取得内存页以及上下文回调的未知效果都保留。未观察到不能等同于不存在。完整状态和范围以报告 `tree/summary.json` 为准。

各批均检查暂停状态、数据库身份和基址，并核验锚点。续读链表也检查链头未变化。但本实现不记录 resume/re-stop 事件序列，不能称为原子快照。采集期间应保持当前暂停现场。

## service internal 的证据链

当前恢复的正向路径是 `(config)# service internal <cr>`，关键词 internal 为 RVA `0x340C1FD8`，EOL 为 `0x340C2258`，handler 为 `0xDE9A730`，selector 为 20。其余公共配置回调效果仍有未知，完整路径保存在报告中。

普通 CLI 分支的启用变量为 RVA `0x37B1B5F8`，本次 BE32 值为 0。关键词访问检查 `0xE38E8D0` 有一个直接条件：权限描述的 native-u64 mask `0x100` 成立，且启用变量为 0 时拒绝。采集器只按已审查的这个表达式标注结果，不调用目标谓词，不将被拒绝的路径从图中删除。其余权限和上下文检查仍不自动求值。

首次正向启用且非 NVGEN 时，handler 还会在首次标志 `0x3CB54594` 为 0 时调用 `0xDF440B0`，之后将该标志置 1。辅助函数遍历两张命令描述链，调用 `0xDF441B0` 按命令字符串定位匹配的权限描述并修改标志。本次两张链各有 59、18 条记录，原始字符串、重复项、模式指针和更新状态均已导出。某些更新状态已非零不能证明由本次 service internal 执行造成，当前首次标志仍为 0。

已审查的该辅助路径没有出现 Parser Linkage 创建或注册调用。因此当前证据支持“已有命令的状态门控和描述标志变化”。handler 还有共享回调分发，未逐个核对其传递效果，不能据此断言所有后续影响都已排除。另一个样本、版本或命令族也应重新审查。

Cisco 的部分 IOS XE 发布说明将 EXEC 隐藏命令与配置模式隐藏命令分开：前者需要 service internal，后者不一定需要。这是相应产品版本的公开行为说明，不证明当前样本如何实现。[Cisco 官方说明，Accessing Hidden Commands](https://www.cisco.com/c/en/us/td/docs/switches/lan/catalyst9200/software/release/17-9/release_notes/ol-17-9-9200/important_notes.pdf)。

## 工具入口

- `tools/capture_debugger_memory.py`：读取请求 JSON 中明确列出的链布局、状态和 RVA/运行时 VA 范围；先验证暂停状态、主模块与不可变锚点。使用调试器读取，不回退到 IDB。
- `tools/collect_runtime_linkage.py`：小批续读链表，保留链尾、时间限制、读取错误和跨批环；原始记录另存。
- `tools/collect_runtime_pages.py`：按显式范围分批取得内存页，用于离线解析。`--direct-output` 对应的底层通道要求 IDA 主机与工具共享同一工作目录，返回文件还核验采集键。链表工具及页工具当前使用此共享路径方式；不共享路径的环境需要改用压缩传输。
- `tools/export_runtime_grammar.py`：只读保存的页，按运行时 tagged BE 指针重建图；关联动作语义、handler、已配置状态门控与静态注册，不连接 IDA。
- `tools/build_runtime_report.py`：从保存结果生成中文对照页和可筛选的示例树。

`profiles/lifecycle_api_26_01_02.json` 保存当前样本的 API、布局、service internal 状态与直接门控。通用实现不按 VPDN 或命令名称判断注册；换二进制后需要重新定位和验证 profile。

本次采集请求、各批输出与输入哈希均在 `reports/runtime-comparison-20261029/`。复现离线报告可执行：

```powershell
python tools/export_runtime_grammar.py reports/vpdn-full-graph.json --pages reports/runtime-comparison-20261029/grammar-pages --pages reports/runtime-comparison-20261029/extra-pages-1 --pages reports/runtime-comparison-20261029/extra-pages-2 --pages reports/runtime-comparison-20261029/extra-pages-3 --pages reports/runtime-comparison-20261029/extra-pages-4 --cache-capture reports/runtime-comparison-20261029/lists-cached-000.json --linkage reports/runtime-comparison-20261029/linkage-complete/lists.json --output reports/runtime-comparison-20261029/tree
python tools/build_runtime_report.py reports/runtime-comparison-20261029
```

这些命令不会运行设备 CLI、调用 handler、改变调试执行状态或修改目标内存。
